Submitting a Prompt or Skill

There's no separate "create a prompt" page floating on its own — every new prompt or skill is created from inside a Workspace, including the Community Workspace if your goal is to get it onto the public Home feed.

Starting a submission​

  1. Open a Workspace (the Community Workspace, or one of your own).
  2. Click + Submit Prompt / Skill (Community Workspace) or + Add Prompt / Skill (your own workspace).
  3. Choose Submit Prompt, Submit Skill, or Link Skill via GitHub.

Filling out the form​

  • Type — Prompt or Skill
  • Title (required)
  • Tags — comma-separated; you'll see a live preview of the tag chips
  • Details — optional context about when/why to use it
  • Prompt / Skill body (required) — the actual text. Use {{ variable }} syntax anywhere you want a fill-in blank (see Filling in Placeholders).

As you type, a live preview on the right shows exactly how your tags and placeholders will look, along with a few writing tips:

  • Use {{ variable }} syntax to create fill-in blanks teammates can customize.
  • Keep the title short and searchable.
  • Add context in Details so others know exactly when to use it.
  • Tag consistently so this prompt surfaces in search and filters.

Starting from an existing prompt​

Instead of writing from scratch, click Copy from Public Prompt/Skill to search the existing public library and prefill the form from something similar — a useful starting template.

Submitting multiple prompts at once​

Click Bulk Import to upload up to 20 .txt/.md files at once. You'll get a chance to review each one before saving.

What happens after you submit​

  • Community Workspace: your submission goes to Awaiting Review. An admin will approve or reject it — you'll see the status update on the item.
  • Your own Workspace: it's visible to workspace members immediately, no review needed.

Linking skills from GitHub​

Instead of writing a skill by hand, you can point PromptVault at a GitHub folder:

  1. Choose Link Skill via GitHub.
  2. Paste a GitHub URL pointing at a folder, e.g. https://github.com/owner/repo/tree/main/path/to/skills.
  3. PromptVault syncs every subfolder containing a SKILL.md file as a skill.

Once linked, use Manage Linked GitHub Skills on the workspace to see each linked source (with its last sync date and count), trigger Sync Now to pull in the latest changes, or Remove it. In the Community Workspace, skills synced this way still require admin approval before appearing publicly.
